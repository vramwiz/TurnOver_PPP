# TurnOver_PPP（布をめくる）

TurnOver_PPPは、AviUtl2上の布やカーテンを2点でつまみ、めくり・風揺れ・波打ちを加えるフィルタープラグインです。

透明余白を持つ素材と、画面全体に画像が描かれた素材を自動判定して変形します。

> [!IMPORTANT]
> 現在は開発中です。仕様や保存形式が変更される可能性があります。重要なプロジェクトでは、編集前にバックアップを作成してください。

## 必要環境

- Windows 64-bit
- AviUtl2
- 画像オブジェクト

## インストール

配布ZIP内の`TurnOver_PPP`フォルダーを、次の場所へ配置します。

```text
C:\ProgramData\aviutl2\Plugin\TurnOver_PPP
```

配置後のプラグイン本体は次の場所です。

```text
C:\ProgramData\aviutl2\Plugin\TurnOver_PPP\TurnOver_PPP.auf2
```

AviUtl2を起動中の場合は、終了してから更新してください。

## 基本設定

1. 画像オブジェクトへ`布をめくる`フィルターを追加します。
2. `設定`を押し、布の外周を頂点で囲んで閉じます。
3. 頂点を選択し、表示されるボタンから`1`と`2`のつまみ位置を割り当てます。
4. めくりプレビューで2点をドラッグし、変形を確認します。
5. 設定を保存し、AviUtl2側の`つまみ1 X/Y`と`つまみ2 X/Y`を動かします。

設定画面のプレビューで動かした位置は保存されません。保存されるのは布の外周とつまみ頂点です。

## 主なパラメーター

| 項目 | 内容 |
| --- | --- |
| つまみ1 X / Y | つまみ1を設定頂点から移動するピクセル量 |
| つまみ2 X / Y | つまみ2を設定頂点から移動するピクセル量 |
| 風 | 2つのつまみへ加算する自動風揺れの強さ |
| 周期 | 風揺れと波打ちが1周するフレーム数 |
| 風向 | 風による移動と波の進行方向 |
| 乱れ | 複数の波を合成して周期運動を崩す量 |
| 波打ち | 布面を進む波の変形量 |
| 波数 | 布面に含める波の数 |
| 影響範囲 | つまみ変形が届く半径 |
| 折れ | つまみの移動経路周辺の奥行き短縮量 |
| 陰影 | 折れ影と持ち上がり面の明度差 |
| 裏面 | 持ち上がった面の低彩度・低明度表現 |
| 落影 | 全面画像をめくって空いた領域へ描く影の濃さ |

`風`と`波打ち`は初期値0です。手動のめくりだけを使う場合は、そのままで構いません。

## 素材の判定

- 外周が画像の四辺から1.5%以内に接する場合は、全面画像として扱います。
- 全面画像では、めくって参照元がなくなった部分を透明にします。
- それ以外は透明余白を持つ素材として、設定した布の外周内を変形します。

## 配布ZIPの作成

Release版を作成した後、次を実行します。

```text
Setup\make_release_zip.bat
```

バッチは次を確認してから`Setup\TurnOver_PPP.zip`を作成します。

- `C:\ProgramData\aviutl2\Plugin\TurnOver_PPP\TurnOver_PPP.auf2`が存在すること
- プラグインが最低限のサイズと`MZ`ヘッダーを持つPEファイルであること
- 同じフォルダーにDebug用DLLまたはRSMが残っていないこと
- READMEがTurnOver_PPP用であること
- ZIP内に`TurnOver_PPP\TurnOver_PPP.auf2`と`TurnOver_PPP\README.md`があること
